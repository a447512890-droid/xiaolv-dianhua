# 待办电话需求原型

静态交互原型。启动与目录说明见[项目首页](../README.md)。

## 启动

在仓库根目录执行 `python3 scripts/preview.py`，访问 <http://127.0.0.1:8765/>。页面实际位于 `/原型/`，从同一仓库的 docs 和 assets 读取资料。无需第三方依赖，不能通过 file:// 读取文档。

## 页面

| 分组 | 页面 |
|---|---|
| 沟通 | 拨号、通话中看板、通话总结、待办详情 |
| 通讯录 | 通讯录、最近沟通记录、拨打前回顾 |
| 待办 | 有待办、空状态 |
| 记录 | 沟通历史 |
| 文档 | 客户字段需求、需求列表、更新日志、元数据、商店图 |

点击波纹圆点查看对应模块说明。通话总结直接展示自动创建的待办；未完成可编辑、标记完成，完成后仅可删除。拨号固定 +86，号码须为以 1 开头的 11 位数字；无效时呼叫按钮置灰，不显示校验提示。

## 数据读取

- 模块说明：[需求说明.md](../docs/产品需求/需求说明.md)，运行 `python3 scripts/build_requirements.py` 生成 `requirements-data.js`。
- 需求列表：[需求列表.md](../docs/产品需求/需求列表.md)，直接读取表格：序号、模块标识、需求名称、需求描述、阶段。
- 客户字段：[客户字段需求.md](../docs/产品需求/客户字段需求.md)，直接读取正文与表格；保留 `#structure` 路由。
- 更新日志：[更新日志.md](../docs/更新日志.md)，直接读取表格：日期、属性、描述、修改人；仅一条记录。
- 元数据：分别直接读取[元数据.md](../docs/商店资料/元数据.md)和[元数据2.md](../docs/商店资料/元数据2.md)，标签名为元数据1／元数据2。
- 商店图：读取 `../assets/商店图/manifest.json`，分类为待办版／沟通流程版。图片新增、移动或删除后运行 `python3 scripts/build_store_manifest.py` 重新生成清单，再点击“刷新图片”。

Markdown 读取禁用缓存，修改源文档后点击“刷新内容”。图片清单由目录自动扫描生成，不依赖服务器目录列表或符号链接。生成文件应与源文件一起提交。

## 边界

原型采用虚构客户和通话数据；未接入实际电话、录音、模型、账号、存储或系统提醒事项。商店图为视觉参考，非正式 App 实际截图。
