# 待办电话 App Store 宣传元数据 1

## App 名称

打电话-电话自动札记沟通待办提醒

## 副标题

通话约定自动变待办，跟进不遗漏，待办可溯源

## App 描述

电话里约好的事，别让它停在通话记录里。

我们会帮助你自动把通话中的承诺和约定整理成待办和总结，沟通时还可回顾上次记录和约定
从电话到行动，不忘记每件重要的事。

### 使用场景

情侣共同爱好： 记住彼此的喜好、说过的话，约会时间与地点；
家人生活琐事： 买菜、接送等家务琐事，也能安排得井井有条；
朋友聚会安排： 记住聚会时间、地点和彼此的约定；
工作面试邀约： 记清面试时间与地点，不错过每一次机会；
语音会议沟通： 留住关键决策、讨论结论和后续安排；
客户订货沟通： 记下商品规格、订购数量、交付时间；
