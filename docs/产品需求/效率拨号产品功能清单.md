# 待办电话功能清单

## 沟通入口

- [ ] “沟通”作为首个标签，展示拨号键盘、号码输入与删除、呼叫按钮
- [ ] 可选择已有关联联系人；号码未匹配联系人时，通话看板展示无历史资料的状态

## 通讯录

- [ ] 底部“通讯录”入口包含“通讯录”和“最近沟通记录”两个标签页
- [ ] 通讯录支持搜索与查看联系人；最近沟通记录按时间倒序展示并可打开回顾

## 通话前

- [ ] 展示联系人资料、最近沟通、上次承诺和待办

## 通话中

- [ ] 看板上方展示位于联系人信息右侧的通话时长，以及静音、扬声器、挂断三个圆形图标按钮及其状态；真实系统通话控制能力待验证
- [ ] 展示通话看板，方便用户在通话过程中查看联系人上下文
- [ ] 看板重点展示联系人上一次通话总结，包括联系人需求、沟通结论和约定的下一步
- [ ] 同时展示最近沟通、未完成承诺和待办；没有历史总结时展示基础联系人资料与最近沟通

## 通话后

- [ ] 总结正文包含沟通摘要、关键要点、约定与待办。
- [ ] 摘要为 1 段，优先控制在 100 字以内；关键要点最多 5 条，没有则隐藏。
- [ ] 要点涵盖事实、结论和未解决问题，不固定销售类别，不输出意向、情绪评分及无依据建议。
- [ ] 我方明确行动自动进入我的待办；对方承诺仅保留为约定；双方事项只将可明确拆出的我方行动创建待办。
- [ ] 待办展示事项、执行方、截止时间、状态、原文依据；时间未明确留空，没有明确行动不生成。
- [ ] 完整转录、服务器录音播放作为独立查证入口；当前未接入实际录音服务。

## 待办操作规则

- 未完成的待办可编辑、标记完成。
- 已完成的待办仅可删除，不可编辑或恢复待完成。删除后从联系人看板、通话总结和待办列表同步移除；原始通话记录仍可回看。
- 通话中看板按“联系人资料”“上次沟通”“约定与待办”“未关联联系人”分别提供对应的模块说明。

## 联系人资料维护

通讯录和拨打前回顾提供通用资料编辑入口，支持关系、所属组织（选填）、重要事项和备注；不设置职务与联系目的字段。一个联系人最多 10 个电话号码，支持添加、修改、删除，号码遵循 +86、以 1 开头的 11 位数字规则，禁止同一联系人内重复号码；回顾页可选择号码呼叫。当前静态原型保存于浏览会话内，刷新恢复初始资料。

## 联系人创建来源（已确认）

支持手动新建联系人，也可将拨号记录中的联系人添加至通讯录成为联系人；不支持系统通讯录导入。新增入口和拨号记录添加流程尚待实现。

## 我的与会员

底部新增我的标签，展示用户昵称、ID、会员状态和独立的会员充值入口；会员充值页展示周／月／年方案。我的还提供隐私政策、用户协议、关于我们页面，关于我们中提供注销账号入口。当前协议为原型草案，注销服务未接入。会员可呼叫并生成新的总结和待办；非会员仅可查看过去的总结和待办，历史任务不提供编辑、完成或删除。通讯录维护权限待确认。交易核验成功后会员时长追加到账，不覆盖当前会员剩余时长；具体节点见《订阅会员流程.md》。价格、支付渠道、续费规则、跨套餐换算与会员有效期核验待确认，当前原型未接入支付或恢复购买服务。恢复购买入口与独立流程图已展示，交易核验及账户关联规则见《恢复购买流程.md》，仍待确认。

“我的”页面内的“非会员／会员”标签用于分别评审状态，不是正式产品的会员切换入口。昵称与 ID 为占位数据；实际会员须由订阅服务核验。

## 呼叫模式（已确认）

- 呼叫按钮下方可切换待办拨号（默认）和普通拨号。
- 待办拨号先弹出 400-846-1658 拨打框，确认后拨打该号码并进入 App 内通话流程；普通拨号调用系统电话，不自动生成总结和待办。
- 沿用会员呼叫权限；实际 App 内呼叫服务尚待接入。

## 录音文件存储（已确认）

- 录音文件保存在服务器。
- 保存期限、删除规则及本地缓存策略待确认；服务器存储与转录服务尚未接入。

## 状态页面组织

- “我的”在同一页面内通过标签切换会员和非会员状态。
- 在原型手机屏幕外通过标签切换“待办”页的空状态和有待办状态；App 页面本身不显示此控件。
