# 待办电话功能清单

## 沟通入口

- [ ] “沟通”作为首个标签，展示拨号键盘、号码输入与删除、呼叫按钮
- [ ] 可选择已有关联客户；号码未匹配客户时，通话看板展示无历史资料的状态

## 通讯录

- [ ] 底部“通讯录”入口包含“通讯录”和“最近沟通记录”两个标签页
- [ ] 通讯录支持搜索与查看联系人；最近沟通记录按时间倒序展示并可打开回顾

## 通话前

- [ ] 展示客户资料、最近沟通、上次承诺和待办

## 通话中

- [ ] 看板上方展示通话时长、静音、通话键盘、扬声器和挂断及其状态；真实系统通话控制能力待验证
- [ ] 展示客户沟通看板，方便销售在通话过程中查看客户上下文
- [ ] 看板重点展示客户上一次通话总结，包括客户需求、沟通结论和约定的下一步
- [ ] 同时展示最近沟通、未完成承诺和待办；没有历史总结时展示基础客户资料与最近沟通

## 通话后

- [ ] 将通话语音转成文字并生成转录
- [ ] AI 识别并标注沟通重点：价格、竞品、预算、异议、决策人等
- [ ] AI 识别沟通中的情绪及变化，如积极、犹豫、焦虑或不满；提供原文或语气依据及时间位置，证据不足时标记待确认
- [ ] AI 根据客户表达建议跟进状态：有意向、需要方案、暂缓或未判断
- [ ] AI 从对话中识别明确的承诺或约定，提议行动项，例如“周五发报价”
- [ ] 展示识别结果的原文依据和时间位置，供销售核对
- [ ] 明确约定的行动项自动创建为待办并关联客户、通话和原文，无需确认创建；创建后可编辑；待办页面分别展示空状态和有待办状态

## 待办操作规则

- 未完成的待办可编辑、标记完成。
- 已完成的待办仅可删除，不可编辑或恢复待完成。删除后从客户看板、通话总结和待办列表同步移除；原始通话记录仍可回看。
- 通话中看板按“客户资料”“上次沟通”“约定与待办”“未关联客户”分别提供对应的模块说明。
