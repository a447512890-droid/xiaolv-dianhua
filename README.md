## 本地预览

需要 Python 3，无需安装第三方依赖。在仓库根目录执行：

```sh
python3 scripts/preview.py
```

打开 <http://127.0.0.1:8765/>，自动进入原型目录；可用 `--port 8766` 指定其他端口。服务以仓库根目录提供文件，仅监听本机。按 Ctrl+C 结束。

也可在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8765/原型/`。不要以原型目录为服务根目录，否则无法读取同仓库的 docs 和 assets。请使用 HTTP 预览，不要直接双击 HTML。

## 数据源与生成文件

| 内容 | 唯一源文件 | 更新方式 |
|---|---|---|
| 模块说明 | `docs/产品需求/需求说明.md` | 运行 `python3 scripts/build_requirements.py`，刷新原型 |
| 需求列表 | `docs/产品需求/需求列表.md` | 页面点击“刷新内容” |
| 联系人字段 | `docs/产品需求/客户字段需求.md` | 页面点击“刷新内容” |
| 更新日志 | `docs/更新日志.md` | 页面点击“刷新内容” |
| 元数据标签页 | `docs/商店资料/元数据.md`、`元数据2.md` | 页面点击“刷新内容” |
| 商店图标签页 | `assets/商店图/` 两个分类目录 | 运行 `python3 scripts/build_store_manifest.py`，页面点击“刷新图片” |

`原型/requirements-data.js` 和 `assets/商店图/manifest.json` 是生成文件，随源文件一并提交，使克隆后的项目可直接预览。无需手动编辑生成文件。Markdown 页面仍直接读取源文档，不复制第二份文档、不使用符号链接。

## 当前交互规则

- 拨号固定 +86，仅接受以 1 开头的 11 位手机号；不符合时仅禁用呼叫按钮。
- 通话看板按“联系人资料／上次沟通／约定与待办”分别提供模块说明，入口为波纹圆点。
- 明确约定自动创建待办；总结直接展示联系人待办。
- 未完成待办可编辑、标记完成；完成后仅可删除。
- 待办提供有待办和空状态两个独立页面。
- 当前没有内容来源与授权、联系人决策进展独立页面。

联系人、公司和通话内容为虚构数据。原型未接入实际电话、录音、模型服务、账号、存储或系统提醒事项。

## GitHub 提交范围

提交本仓库中的文档、脚本、代码、图片及生成文件。`.gitignore` 排除系统文件、Python 缓存、环境配置和临时文件。更新日志遵循已确认要求，仅保留创建原型的一条记录。

本地预览服务不是生产服务。若后续需要在线托管，应以仓库根目录保留 docs、assets、原型三者的相对路径，入口设为原型目录。

## GitHub Pages 展示文件

运行 `python3 scripts/build_pages.py` 生成 `.pages/` 发布目录，或通过 `--output` 指定新的空目录。生成物包含原型页面、页面实际读取的 Markdown、商店图及根入口跳转页；不包含 BRD、AI 提示词、协作文件、Git 历史和本地预览脚本。模块说明包含在 `requirements-data.js` 中，发布后可公开查看。

`.pages/` 已加入忽略规则。发布前若修改模块说明或商店图，应先运行对应生成脚本。发布入口为输出目录的 `index.html`，原型仍保留 `#` 页面路由。
